Aplicacion para agendar citas en linea para clientes como esteticas.

## Requisitos del prototipo

- **Prototipo funcional.** Recorre de inicio a fin el proceso descrito en `PROYECTO.md`.
- **Se levanta y se ejecuta siguiendo únicamente este README**, sin depender del equipo donde se
  construyó: todo lo necesario está versionado y no quedan rutas, claves ni configuraciones
  locales. La comprobación de referencia es clonar el repositorio desde cero en una carpeta
  limpia y levantarlo desde ahí.
- **Persiste su estado en un motor de base de datos real.** SQLite cuenta como motor; no se
  aceptan sustitutos como archivos JSON, hojas de cálculo o almacenamiento en memoria.

*(Instrucciones de instalación y arranque: se completan cuando exista el prototipo. Por ahora
este README documenta el compromiso, no los pasos — todavía no hay código.)*
